Exercise in R: Prokaryotic regulation (recap)

Goal

By the end of this exercise you should be able to:

  • write the Jacob–Monod rules for the lac operon as one R function;
  • build every combination of genotypes with tidyr::expand_grid() and apply your function to each row;
  • check a model against a table of known results with left_join().

Before you start

This page builds on the by-hand part of the Exercise, so do that first. You need the packages readr, dplyr, tidyr, stringr and purrr. Download jacob_monod_table.csv and save it in a data/ folder of your R project. It lists the expected phenotypes of eleven classic strains; the course team typed them in from the textbook summaries of Jacob and Monod’s work, so they are qualitative results, not measurements.

library(readr)
library(dplyr)
library(tidyr)
library(stringr)
library(purrr)

Tasks

New idiom today: expand_grid() from tidyr. It makes a tibble with one row for every combination of the vectors you give it, like writing out every cell of a Punnett square. expand_grid(x = 1:2, y = c("a", "b")) gives four rows: 1 a, 1 b, 2 a, 2 b.

We write a genotype as a string such as "I+ O+ Z+ Y+", with - for loss of function, s for the super-repressor and c for the constitutive operator. An F′ genotype uses the same format, or "none" for a haploid. str_match() pulls out the character after a gene letter: str_match("I+ Oc Z- Y+", "O(.)")[, 2] is "c".

R1. (the rules as a function) Complete lac_expression(chrom, fprime, lactose). It returns a named logical vector: is active β-galactosidase made, and is permease made? Follow the three steps from the Background of the exercise: which repressor is in the cell, which operators are free, and what each transcribed copy makes.

lac_expression <- function(chrom, fprime, lactose) {
  copies <- if (fprime == "none") chrom else c(chrom, fprime)
  I <- str_match(copies, "I(.)")[, 2]   # one value per copy: "+", "-" or "s"
  O <- str_match(copies, "O(.)")[, 2]
  Z <- str_match(copies, "Z(.)")[, 2]
  Y <- str_match(copies, "Y(.)")[, 2]
  # step 1: are normal operators blocked? (TRUE/FALSE)
  repressed <- ...
  # step 2: which copies are transcribed?
  on <- ...
  # step 3: what do the transcribed copies make?
  c(bgal = any(on & Z == "+"), permease = any(on & Y == "+"))
}

lac_expression("I+ O+ Z+ Y+", "none", lactose = FALSE)
lac_expression("I+ O+ Z+ Y+", "none", lactose = TRUE)
lac_expression("I- O+ Z+ Y+", "I+ O+ Z+ Y+", lactose = FALSE)

R2. (phenotype) Write phenotype(chrom, fprime, enzyme), which calls lac_expression() without and with lactose and returns "inducible", "constitutive" or "none" for one enzyme ("bgal" or "permease"). Test it on Oc and on F′ I+ / Is.

R3. (every strain) Use expand_grid() to build all single copies: three lacI alleles × two lacO × two lacZ × two lacY. Paste each row into a genotype string. Then use expand_grid() again to pair every chromosome with every F′ (including "none"). Add the two phenotypes with map2_chr(), which works like map_chr() but walks along two vectors at once. How many strains are there? How many are inducible for β-gal?

copies <- expand_grid(I = c("+", "-", "s"), O = c("+", "c"), Z = c("+", "-"), Y = c("+", "-")) |>
  mutate(genotype = paste0("I", I, " O", O, " Z", Z, " Y", Y))

all_cells <- expand_grid(chrom = copies$genotype, fprime = c("none", copies$genotype)) |>
  mutate(bgal     = map2_chr(chrom, fprime, \(c, f) phenotype(c, f, "bgal")),
         permease = map2_chr(chrom, fprime, \(c, f) phenotype(c, f, "permease")))

R4. (check against Jacob and Monod) Read data/jacob_monod_table.csv. Join your model’s predictions onto it with left_join() by chrom and fprime, and add a column agree that is TRUE when both enzymes match. Does your function reproduce every classic result?

R5. (looking for cis action) Use filter() on all_cells to list merodiploids whose chromosome carries Oc but whose β-galactosidase is nevertheless inducible. What do these strains have in common, and what do they show about lacO? Then count the haploid phenotype combinations: how many of the 24 haploids are both β-gal-none and permease-none, and why?

Solutions

Solutions: In R

R1. Any Is repressor blocks every normal operator, whatever the inducer. Otherwise normal repressor blocks normal operators only without inducer. With no working repressor at all, nothing is blocked. An Oc copy is transcribed whatever happens.

lac_expression <- function(chrom, fprime, lactose) {
  copies <- if (fprime == "none") chrom else c(chrom, fprime)
  I <- str_match(copies, "I(.)")[, 2]
  O <- str_match(copies, "O(.)")[, 2]
  Z <- str_match(copies, "Z(.)")[, 2]
  Y <- str_match(copies, "Y(.)")[, 2]
  repressed <- if (any(I == "s")) TRUE else if (any(I == "+")) !lactose else FALSE
  on <- O == "c" | !repressed
  c(bgal = any(on & Z == "+"), permease = any(on & Y == "+"))
}
lac_expression("I+ O+ Z+ Y+", "none", lactose = FALSE)
    bgal permease
   FALSE    FALSE
lac_expression("I+ O+ Z+ Y+", "none", lactose = TRUE)
    bgal permease
    TRUE     TRUE
lac_expression("I- O+ Z+ Y+", "I+ O+ Z+ Y+", lactose = FALSE)
    bgal permease
   FALSE    FALSE

The last one is F′ I+ / I− without lactose: repressed, because the F′ repressor works in trans.

R2.

phenotype <- function(chrom, fprime, enzyme) {
  off <- lac_expression(chrom, fprime, lactose = FALSE)[[enzyme]]
  on  <- lac_expression(chrom, fprime, lactose = TRUE)[[enzyme]]
  if (off) "constitutive" else if (on) "inducible" else "none"
}
phenotype("I+ Oc Z+ Y+", "none", "bgal")
[1] "constitutive"
phenotype("Is O+ Z+ Y+", "I+ O+ Z+ Y+", "bgal")
[1] "none"

All eleven classic results agree. Three short rules (super-repressor beats everything except Oc; normal repressor needs no inducer; Oc is always on) explain the whole table. That is what Jacob and Monod’s model achieved.
