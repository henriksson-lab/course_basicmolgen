# Data for Chromosome theory & sex linkage

- `morgan1910.csv`: Morgan's white-eye counts in *Drosophila melanogaster*. Source: Morgan TH (1910) "Sex limited inheritance in Drosophila", *Science* 32(812):120–122, PMID 17759620. Numbers checked against the ESP Foundations reprint (<http://www.esp.org/foundations/genetics/classical/thm-10a.pdf>) on 2026-11-20. Real data.
- `human_chromosomes.csv`: lengths of the human chromosomes 1–22, X and Y in base pairs, from the Ensembl REST API (`https://rest.ensembl.org/info/assembly/homo_sapiens`), assembly GRCh38.p14, retrieved 2026-11-20. Real data.
